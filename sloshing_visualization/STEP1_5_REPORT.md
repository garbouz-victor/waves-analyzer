# STEP 1.5 — independent and stiff validation

База: `ffd287c5d1bdb797510dcb9f732b3368a2cfaa73`, first iteration.
Дата исследования: 2026-09-06. Ниже — измеренные результаты STEP 1.5,
не план эксперимента. Production-анимация в этом этапе не создавалась.

## Audit of STEP 1

Аудит выполнен до изменений операторов. Математических ошибок в production
weak formulation не обнаружено. Для `T=-qI+2nu D`, `Tn=-g eta n` интегрирование
по частям даёт
`(v_dot,phi)+2nu(Dv,Dphi)-(q,div phi)+g<eta,phi_z>=0`.

| Проверка | Вывод аудита |
|---|---|
| Pressure | B=(p,div v), momentum содержит −Bᵀq: знак верен |
| Gravity | +gC eta слева, −gC eta справа: знак верен |
| Viscosity | K=2nu∫D:D; коэффициент 2 верен |
| Kinematics | eta_dot=Rv, знак соответствует z вверх |
| Surface mass | S — точная P2 boundary mass, включая endpoint basis functions |
| Trace | R выбирает вертикальные P2 DOF на z=0; C=RᵀS |
| Walls | Исключены обе компоненты на трёх стенках и углах; endpoint строки R нулевые |
| Energy | Midpoint: ΔE+dt v_midᵀK v_mid=0 для нулевой силы |
| Pressure recovery | Система для ускорения с B a=0 восстанавливает q в момент snapshot |
| Pressure constant | Задана traction; вычитать среднее q или удалять pressure equation нельзя |

Квадратура порядка 6 достаточна для матриц P2/P1. Для аналитических ошибок MMS
использована более высокая квадратура. Слабая div не подменяет сильную.
В STEP 1 тесты подтверждали прежде всего внутреннюю согласованность;
пространственная правильность независимо ещё не была проверена.

Единицы: u,w и no-slip residuals — m/s; q — m²/s²; eta/contact error — m;
∫eta dx и volume error — m²; slope — безразмерный; omega — 1/s;
объёмные L2 div и grad v в 2D — m/s, их отношение безразмерное;
E — m⁴/s², dissipation — m⁴/s³ (на плотность и поперечный размах).
Энергобаланс в абсолютной форме — m⁴/s², относительный безразмерен.

Убрана повторная амплитудная нормировка наклона. Small-slope warning теперь
использует только физический `max |eta_x| > 0.3`. Production alpha=2° и
остальные параметры первого расчёта сохранены.

## Manufactured spatial convergence

Exact fields заданы streamfunction из задания и независимо дифференцируются
SymPy. Все четыре symbolic tests прошли: incompressibility, solid no-slip,
kinematic/pinned conditions, обе формы momentum и обе компоненты traction.
Обе компоненты r ненулевые. Аналитическое pressure также ненулевое; его
константа при измерении ошибки **не** вычитается.

## Midpoint vs SDIRK2 stiff behavior

Для z=lambda*dt функции устойчивости:
`R_mid=(1+z/2)/(1-z/2)`, `R_sdirk=(1+(1-2gamma)z)/(1-gamma*z)²`.
На отрицательной вещественной полуоси пределы соответственно −1 и 0.
Для SDIRK2 на мнимой оси
`|den(iy)|²−|num(iy)|²=gamma⁴*y⁴>=0`; единственный полюс `1/gamma>0`.
Аналитичность в левой полуплоскости и принцип максимума модуля дают
A-stability, а нулевой предел на бесконечности — L-stability. Это тождество
и предел дополнительно проверены символически, а не только на отрицательных
вещественных тестовых lambda.

| lambda*dt | Midpoint amplification | SDIRK2 amplification | exp(lambda*dt) |
|---|---:|---:|---:|
| −0.01 | 0.9900497512 | 0.9900497937 | 0.9900498337 |
| −1 | 0.3333333333 | 0.3504402628 | 0.3678794412 |
| −100 | −0.9607843137 | −0.0440587103 | 3.720076e-44 |
| −10000 | −0.9996000800 | −0.0004823967 | ниже float64, exp(−10000) |

Tiny FEM: 4×6, production geometry d=10, nu=1. Собственная мода реальная,
lambda=−3508.585288 s⁻¹, dt=0.0285015161 s, lambda*dt=−100.
Начальная норма `(vᵀMv+g etaᵀS eta)^0.5=1`. Это тест свойств времени
на дискретной моде, **не** независимый пространственный benchmark (его роль
выполняет MMS).

Знак midpoint amplitude чередуется −,+,−,+,−. SDIRK2 на столь жёстком

functions; сглаживание omega не применялось.

Все шесть отдельных wall residuals равны нулю, не только их агрегат.
Максимальный рост энергии за **внутренний шаг** равен нулю у обоих методов

больше слабой: Taylor–Hood не pointwise divergence-free. Это дискретизационная
ошибка, а не скрываемый ноль; её сеточное уменьшение показано отдельно.

SDIRK2 дискретный энергобаланс отличается от midpoint. Для стадийных
производных k=(k_v,k_eta), G=diag(M,gS):

```
Delta E + dt sum_i b_i V_i^T K V_i - dt sum_i b_i V_i^T F_i + Q_RK = 0
Q_RK = dt^2 * gamma^2 * (E(k_2) - E(k_1))
```

У midpoint Q_RK=0. У SDIRK2 Q_RK знаковый и **не является вязким теплом**;
он хранится отдельно. Например, nu=0.01, dt=0.005, E(0)=3.9844282168e-5:

| Integrator | E(0.5), m⁴/s² | Cumulative viscous loss, m⁴/s² | Q_RK cumulative, m⁴/s² |
|---|---:|---:|---:|
| midpoint | 3.3773723414e-5 | 6.0705587538e-6 | 0 |
| sdirk2 | 3.3773463949e-5 | 6.0709704457e-6 | −1.5222642451e-10 |

Энергетическая поправка мала, но намеренно не спрятана внутри viscosity.
Для production work=0; для MMS тестируется также ненулевая работа силы.
Монотонность production energy здесь измерена, а не выведена из ошибочного
утверждения об algebraic stability SDIRK2.

## Recommendation for the next physical animation calculation

**Выбор по измерениям: SDIRK2, dt=0.00125 s.** Это самый мелкий из
проверенных production-like шагов. Он подавляет stiff-mode residue, который
у midpoint заметен в omega при почти совпадающей eta. При dt=0.0025 SDIRK2
уже достаточен для согласования snapshot wall L2 с dt/2 лучше 0.007%
для nu=0.01…1; более осторожный выбор 0.00125 мотивирован ранними
internal-step diagnostics и будущим акцентом на vorticity.

| Параметр | Рекомендация и граница утверждения |
|---|---|
| alpha | 0.02° для следующего физического near-contact расчёта; 0.2° оставить для формального comparison/breakdown |
| mesh | medium 80×140 как старт; fine comparison обязателен для новых corner/длинновременных утверждений |
| integrator | sdirk2 |
| dt | 0.00125 s |
| snapshot_dt | 0.005 s (4 шага), чтобы лучше сохранить начало движения; это выбор sampling, не новая PDE |
| Проверенный временной интервал | 0…0.5 s для temporal study; contact mesh study — до 0.1 s |
| Проверенные nu | 0.01, 0.1, 1.0 m²/s; nu=0.001 ещё не проверена этим study |

Угол 0.02° — **вывод из линейного масштабирования**, не отдельно выполненный
run: все поля масштабируются как tan(alpha), энергии — как tan²(alpha).
Из max slope=0.879336 при 0.2° следует примерно 0.087933 при 0.02° на medium
за тот же интервал. Это не гарантирует малый slope на finer mesh или за 5 s.
Default alpha=2° и default midpoint сохранены ради reproducibility исходного
commit. В configs есть оба явно запрошенных примера 0.2° и 2°.

Не следует утверждать, что dt=0.00125 полностью разрешает всякий pointwise
угловой transient: dt/2 ниже этого значения в production study отсутствует.
Перед анимацией 0…5 s нужно продолжить физический run с теми же diagnostics,
проверить малые наклоны на всём интервале и заново оценить mesh/contact
чувствительность. Здесь STEP 2 не начинается.

Остаются ограничения: linear fixed-domain approximation, ненулевая сильная
div у Taylor–Hood, негладкая локальная контактная структура при strict
no-slip и sigma=0. Нет moving contact line, wetting, deposition/dewetting,
вертикальной плёнки или final wall drainage. L-stable интегратор не
устраняет пространственную сингулярность и не заменяет модель контакта.

## Reproducibility, execution notes and tests

Все исходные 43 STEP 1 tests сохранены и прошли после изменений; новое
поле наклона проверяется без повторного множителя амплитуды. Ни один порог
не ослаблен, чтобы скрыть неудачную сходимость. MMS acceptance limits
установлены после фактического измерения orders.

Полный журнал tests и итоговый статус приведены в
[tests.xml](validation_results/tests.xml); читаемый перечень —
[TEST_RESULTS.md](validation_results/TEST_RESULTS.md).
Итог объединённого запуска: **73 passed, 9 warnings, 107.55 s**.
Из них 71 default test и 2 tests с marker validation. Warnings: один
о small-slope breakdown в исходном contact test (0.3037) и восемь о сильной
div на намеренно маленьких сетках (relative div 0.173…0.465). Они не
подавлены; production medium diagnostics приведены отдельно выше.
Команды воспроизведения и разделение default/validation suite — в README.
Scientific plots проверены отдельно от production renderer, которого нет.

Во время длинного batch был остановлен процесс для изменения организации
вычислений. Он оставил незавершённый HDF5 nu=0.1, SDIRK2, dt=0.00125;
файл сохранён отдельно в локальном ignored `time/interrupted/`, не использован
в таблицах. Run выполнен заново и завершён. Это interruption/cache failure,
не численная ошибка FEM; добавлен тест отказа от повторного использования
повреждённого кэша. Failed/incompatible files автоматически не перезаписываются.

CSV/JSON и научные PDF/PNG включаются в commit, большие восстановимые HDF5
validation caches остаются локальными и ignored. Скрипты воспроизводят их
из config; новый `--output` даёт независимый повтор. Из исторических CSV/HDF5
удалён только устаревший diagnostic наклона, реальные поля не пересчитаны.
