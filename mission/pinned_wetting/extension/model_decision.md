## Уравнения основной жидкости

Первый целевой путь — линейные уравнения вязких гравитационных колебаний:
u_t = div T, div u = 0, T = -q I + 2νD(u) (на единицу плотности).
q — давление относительно гидростатики. На reference-плоскости z=0:
T n = -gη n и η_t = w. На боковых стенках:
u·n=0; (T n)_t = -(ν/b)u_tangent. На дне обе компоненты u=0.
Начальные данные: η=x tan(2°), u=0. Конечное дно z=-10 м — физическая граница
этого case; бесконечная глубина не заявляется.

Здесь z=0 не крышка: это плоскость линеаризации свободной поверхности. Из η
восстанавливается L_macro={-d≤z≤η(x,t)}, в том числе выше z=0. Численной верхней
крышки/границы headroom в данном surface-graph методе нет; массив η не ограничен
сверху. Для рисунка будет выбран фиксированный запас выше всех native η без
изменения поля. Это не нелинейный moving-domain Navier–Stokes.

P2/P1 FEM: из свободных DOF боковых стенок исключается только горизонтальная
компонента, а дно остаётся полным Dirichlet. Вертикальные endpoint DOF входят
в систему. Поэтому R_L/R_R=η(±a) и Rdot=w(±a,0) вычисляются уравнениями.
Ни высота гребня внутри сосуда, ни её экстраполяция не заменяют wall trace.

Слабая форма содержит положительную матрицу
K=K_bulk+K_wall, K_wall=(ν/b)∫sides u_tangent·v_tangent.
При касательной ez знаки: слева ∂xw+∂zu=w/b, справа ∂xw+∂zu=-w/b.
E=ρ/2(vᵀMv+gηᵀSη), dE/dt=-ρvᵀK_bulk v-ρvᵀK_wall v.
Оба интеграла потерь сохраняются отдельно по тем же SDIRK2 стадиям; подписанная
RK correction не объявляется физической диссипацией. Navier BC проверяется в
вариационном смысле, дополнительно показывается сходимость traction residual.
В самой точке пересечения свободной поверхности и Robin-стенки гладкость
напряжения заранее не предполагается; точечный residual там не подменяет слабую норму.

## Второй, независимый закон — остаточное покрытие

L_total=L_macro ∪ W_L ∪ W_R, W_i={(x_i,z):-d≤z≤H_i}.
H обновляется максимумом действительного wall R после каждого принятого шага,
не по render frames. Состояние хранит H, непрерывные интервалы W и marker catalog;
liquid_present(side,z) работает без renderer. Начальная сухая область не покрыта.
Navier slip сам по себе не обеспечивает эту необратимость: это два отдельных
постулированных закона. Толщина, объём, инерция и отдельная обратная динамика слоя,
включая adsorption work, не вычисляются: явная ведущепорядковая односторонняя
аппроксимация, не доказанная молекулярная модель.

P1/P2 неизменны. Новый marker создаётся только при подтверждении local record
последующим accepted sample; координаты берутся из native peak state и затем
не меняются. Numerical record floor 0.1 мм выбран до solve; финальная различимость
сопоставляется с mesh/dt uncertainty. Отсутствие новых рекордов — допустимый исход.

## Проверки до выпуска

Нетривиальный side-wall benchmark: steady channel, w(x)=G/(2ν)(a²-x²+2ab).
Он проверяет трение/оба знака независимо от sloshing (дно/поверхность в этом
отдельном benchmark не изображают сосуд). Дополнительно: точное нулевое равновесие,
балансы массы/энергии, слабая несжимаемость, no-penetration/no-slip дна, checkpoint
continuation и negative tests. Исходные обязательные gates сохраняются кроме
явно заменённого side BC; дополнение — ACCEPTANCE_ADDENDUM.yaml.

Линейная применимость проверяется по всему native горизонту: max|η|/a≤0.05,
max|η_x|≤0.30 по точным P2 производным всех рёбер, включая стеночные.
Также сообщаются max|η|/b и индикаторы отброшенных η∂zw-u∂xη и u·∇u с
фиксированными начальными масштабами. Эти критерии не доказывают 5% физической
ошибки: пороги mesh/dt относятся к численному уточнению данной линейной модели.
Точные нормировки: A0=g|tan(alpha)|, U0=sqrt(g*a)|tan(alpha)|;
max|u·grad u|/A0 и max|eta*∂z w-u*∂x eta|/U0 берутся по FE quadrature.
В отличие от точной P2 surface/slope sup эти объёмные/trace индикаторы являются
квадратурными оценками. Их изменение при уточнении также публикуется.
При провале применимости b не подгоняется; потребуется нелинейная геометрия
либо зафиксированный физический/численный blocker.

Основы Navier weak BC/энергии проверены независимым контекстом /root/physics_review.
После pilot автоматически выполняются 5 с, отдельные mesh/dt runs, b sensitivity,
финальный рендер и независимый review. Ни один внутренний PASS не завершает миссию.
