# Карта миссии

Прочитай `MISSION.md`, `PHYSICS.md`, `CONFIG.yaml`, `ACCEPTANCE.yaml`.
Поддерживай один `EXECPLAN.md` и `state.json` вместо бесконечных STEP3A-отчётов.

- Внутренний PASS — переход дальше, не повод ждать нового промпта.
- Нельзя удалять жидкость с однажды смоченного участка модели.
- Изначально поверхность прямая; координаты всех подписанных точек постоянны.
- Расчёт определяет волны и новые рекорды, не storyboard.
- Превью/синтетические fixtures нельзя переименовывать в физический результат.
- Существующий pinned-endpoint solver не предсказывает advancing wall contact.
- Не смягчай acceptance, чтобы получить PASS; исправляй причины и сохраняй evidence.
- Смена физики — не рефакторинг: объясни её и не маскируй оригинальной постановкой.
- Исторические datasets/guards не менять; новая ветка и отдельные run directories.
- Один тяжёлый job, реальные ресурсные лимиты, без платных услуг и auto-push.
- Полный harness ещё не написан: переиспользуй существующее, добавь минимум.
